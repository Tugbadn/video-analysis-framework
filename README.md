# Görüntü İşleme Tabanlı Video Analiz Sistemi

## Proje Hakkında
Bu çalışma, video verileri (`.mp4` vb.) üzerinde görüntü işleme teknikleri kullanarak nesne/hareket analizi gerçekleştiren Python tabanlı bir sistemdir.

## Kullanılan Teknolojiler
* **Dil:** Python 3.x
* **Kütüphaneler:** OpenCV, NumPy, Matplotlib
* **Versiyon Kontrol:** Git & GitHub

## Tamamlanan ve Planlanan Özellikler ilk deney için
- [x] Video girdi/çıktı (I/O) ve kare okuma modülü
- [x] Temel görüntü ön işleme (Filtering, Grayscale)
- [x] Nesne tespiti ve alan analizi algoritmaları
- [x] Veri çıktılarının JSON/CSV formatında dışa aktarımı

## Kurulum ve Çalıştırma
```bash
git clone [https://github.com/kullanici-adiniz/proje-adi.git](https://github.com/kullanici-adiniz/proje-adi.git)
cd proje-adi
